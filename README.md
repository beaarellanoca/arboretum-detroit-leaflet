# Arboretum Detroit Interactive Website

## Project Overview

This repository contains the source code and supporting files for the **Arboretum Detroit Interactive Website**, an open-source digital storytelling platform developed as part of the California State University, Long Beach Master of Science in Geographic Information Science (MSGISci) program.

The website communicates Arboretum Detroit's mission through interactive web mapping, community narratives, historical information, photographs, and GIS analyses. It was developed using HTML, CSS, JavaScript, the Leaflet JavaScript library, and GitHub Pages to provide a sustainable, publicly accessible platform that can be maintained without proprietary software or recurring hosting costs.

---

## Website Features

- Interactive map of Arboretum Detroit restoration sites
- Site-specific popups containing photographs and restoration information
- Community stories and historical narratives
- Detroit environmental context and GIS analyses
- Urban Tree Planting Opportunity analysis
- Environmental Inequity analysis
- Mobile-friendly responsive design
- Public website hosted through GitHub Pages

## Repository Structure

```
Website_Source/
│
├── index.html
│     Main webpage containing the website content.
│
├── style.css
│     Controls the website layout, colors, typography, and responsive design.
│
├── script.js
│     Provides interactive functionality including the Leaflet map, popups,
│     and GeoJSON integration.
│
├── images/
│     Photographs, graphics, and website imagery.
│
├── data/
│     GeoJSON dataset containing Arboretum Detroit restoration site locations.
│
└── README.md
      Project overview and repository information.
```

## Updating the Website

Most website updates can be completed by editing the following files:

| Update | File |
|---------|------|
| Website text | `index.html` |
| Images | `images/` |
| Interactive map | `script.js` |
| Restoration site data | `data/ArbDetroit_Sites.geojson` |
| Website appearance | `style.css` |

Detailed instructions are provided in the **Documentation** folder.
